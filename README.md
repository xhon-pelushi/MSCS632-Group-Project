# Collaborative To-Do List Application

**Course:** MSCS-632 — Advanced Programming Languages  
**University:** University of the Cumberlands  
**Team:** Xhon Pelushi & Sikun Peng  

## Project Overview

This project implements a **Collaborative To-Do List Application** in two programming languages — **Java** and **JavaScript** — as part of a cross-language comparison study. Both implementations provide the same core functionality while demonstrating each language's unique features, paradigms, and approaches to common programming problems.

## Repository Structure

```
MSCS632-Group-Project/
├── java/           # Java implementation
└── javascript/     # JavaScript implementation
```

## Application Features

- Multi-user support with user-specific task views
- Add, remove, and mark tasks as complete
- Task categorization (e.g., Work, Personal, School)
- Task assignment to specific users
- Concurrent access support
  - Java: multi-threading
  - JavaScript: async/await and Promises

## Languages & Key Concepts Demonstrated

| Feature | Java | JavaScript |
|---|---|---|
| Paradigm | Object-Oriented | Prototype-based / Functional |
| Concurrency | Threads (`synchronized`) | async/await, Promises |
| Data Storage | Objects / Collections | JSON |
| Type System | Static, strongly typed | Dynamic, weakly typed |
| Error Handling | Checked Exceptions | try/catch, Promise `.catch()` |
